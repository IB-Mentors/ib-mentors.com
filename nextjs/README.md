# ib-mentors.com in Next.js

A 1:1 rebuild of the IB Mentors Framer site (`amusing-environment-470649.framer.app`) in Next.js 16 (App Router),
React 19, CSS Modules and `motion`: same layout at every width, same Japanese copy, same images and animations. It is
built to replace the static Framer mirror in the repo root (`export.sh` + `scripts/*.py`). **It is not live yet.**

```bash
npm install
npm run dev          # http://localhost:3410
npm run typecheck
npm run lint
npm run build        # NEXT_DIST_DIR=.next-build npm run build to build beside a running dev server
```

## Layout

| Path | What |
|---|---|
| `src/app/**` | Routes, one file each, URLs exactly as Framer's (no trailing slash). CMS detail routes use `generateStaticParams` with the Framer slugs. `not-found.tsx` is Framer's styled 404 (status 404, noindex). |
| `src/app/api/contact` | Endpoint for the three Framer forms (see Env). |
| `src/app/sitemap.xml`, `robots.txt` | Same shape as Framer's sitemap, built from `src/content/`. |
| `src/components/shell/` | `Page` frame, `Navigation`, `Footer`, `SiteCredit` ("Site by Kelin Studio", as production carries it) |
| `src/components/ui/`, `src/components/cards/` | Shared Framer components (`Hero Button` variants, `Load More Button`, `Course Card`, `Team Card`) |
| `src/components/<page>/` | Pages and their sections |
| `src/content/{courses,blogs,teams}.ts` | The Framer CMS collections, generated by `python3 qa/extract-content.py` |
| `src/components/measurement/`, `src/lib/measurement.ts` | GA4 G-13MKYG4YL9, AdSense, Cloudflare Web Analytics beacon, click-ID capture, contact/CTA click events: what `scripts/inject-*.py` added to the mirror, in the house measurement pattern (oglabs.io). |
| `src/lib/meta.ts`, `src/lib/seo-data.ts`, `src/components/measurement/JsonLd.tsx` | Titles, descriptions, canonicals, robots and JSON-LD: a snapshot of what the mirror serves (`python3 qa/gen-seo.py`), with a derived fallback for new CMS entries. |
| `src/app/{tokens,presets,fonts}.css`, `public/framer/`, `public/fonts/` | Framer colour tokens (by token id), text presets as `.p-<id>`, self-hosted fonts, every image (`python3 qa/gen.py`). |
| `public/{ads.txt,llms.txt,SocialPreview.png}` | Copied from the mirror. |

Breakpoints are this Framer project's own: desktop `>= 1380px`, tablet `768..1379.98px`, phone `<= 767.98px`.

## Parity checks

`docs/BUILD-BRIEF.md` is the brief the pages are built to. Reference material is regenerated locally (git-ignored):

```bash
cd qa/framer && cat all-urls.txt | xargs -P 8 -n 1 bash ../fetch-page.sh && cd ../..   # Framer SSR HTML
python3 qa/gen.py                 # modules (prettified), tokens, presets, fonts, images
python3 qa/extract-content.py     # src/content/*.ts
python3 qa/gen-seo.py             # src/lib/seo-data.ts from the mirror in the repo root
node qa/dump.mjs all              # computed-style dumps into qa/ref/
node qa/heights.mjs               # every route, page height live vs ours, 1440/1000/390
node qa/compare.mjs /courses @page 1440,1000,390
node qa/links.mjs                 # internal links, console errors, broken images on ours
```

`OURS_URL` (default `http://localhost:3410`) and `LIVE_URL` point the scripts elsewhere.

## Env

| Var | Why |
|---|---|
| `RESEND_API_KEY` + `LEADS_TO` (+ `LEADS_FROM`) | Form submissions are emailed to the team. Unset: `/api/contact` answers 503 and the forms show their error state. |
| `LEADS_WEBHOOK_URL` + `LEADS_WEBHOOK_SECRET` | Optional: POST each submission to a leads portal first. |
| `SITE_NOINDEX=1` | Preview hosts: `noindex` meta and a disallow-all `robots.txt`. |
